# Skills

Mỗi skill là một tác vụ AI đóng gói. Ví dụ dự kiến:

| Skill | Input | Output |
| :--- | :--- | :--- |
| `generate-ui-test` | URL + mô tả flow | File `.spec.ts` trong `tests/ui/` |
| `generate-api-test` | Endpoint + schema | File `.spec.ts` trong `tests/api/` |
| `heal-locator` | File test bị fail + DOM | Diff gợi ý sửa locator |
